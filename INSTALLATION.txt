QUICK DEPLOYMENT (3 STEPS)
==========================

1. PREPARE SERVER

   SSH into your Debian server:
   $ ssh user@192.168.0.131

   Create deployment directory:
   $ sudo mkdir -p /opt/docker/privstack
   $ sudo chown $USER:$USER /opt/docker/privstack

2. COPY FILES

   From your local machine, copy entire privstack folder:
   $ rsync -av /tmp/privstack/ user@192.168.0.131:/opt/docker/privstack/

   OR manually copy via SCP/SFTP

3. DEPLOY

   SSH into server and run:
   $ cd /opt/docker/privstack
   $ bash QUICK_START.sh

   This will:
   - Generate secure NEXTAUTH_SECRET
   - Create .env file
   - Build Docker image
   - Start container
   - Run health checks

4. Restart container

See DEVELOPMENT.md for detailed examples.

TROUBLESHOOTING
===============

Container won't start:
  $ docker compose logs privstack

  Common causes:
  - DATABASE_PATH invalid
  - NEXTAUTH_SECRET not set
  - Port 8082 in use
  - Docker socket not accessible

Service shows "unreachable":
  - Verify URL in Settings is correct
  - Check service is accessible: curl http://service:port
  - Verify API key is correct
  - Check firewall rules

High memory usage:
  - Reduce widget polling intervals
  - Clear old data from database
  - Restart container

For detailed troubleshooting: See DEPLOYMENT.md
